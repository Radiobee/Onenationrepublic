❖ Step 2 • Important Notice for Apple / macOS Users

macOS Permission & Gatekeeper Workaround

Because IDAOS is distributed as an independent, local-first sovereign binary and we do not currently use a commercial Apple Developer certificate, Apple's built-in Gatekeeper security may display a permission prompt or an "unidentified developer / Apple could not verify" warning the first time you launch the Mac version.

Your binary is completely safe and runs 100% locally on your hardware. You can bypass the macOS permission block in less than 30 seconds using either method below:

❖ Option A: Standard macOS System Settings Method (No Terminal Needed)

  • 1. Extract the downloaded deployment .zip folder onto your Mac Desktop.
  • 2. Control-click (or Right-click) the Mac binary file and select Open.
  • 3. If macOS blocks the file from opening, click Done or Cancel on the popup window.
  • 4. Open your Mac System Settings → click Privacy & Security in the left sidebar → scroll down to the Security section.
  • 5. Click "Open Anyway" next to the blocked file notice and enter your Mac password to permanently authorize IDAOS on your machine.

❖ Option B: Instant Terminal Unlock (Fastest for Apple Silicon Macs)

If you prefer unlocking execution permissions directly via the macOS Terminal app, open Terminal, navigate to the folder where you unzipped the files, and run these two commands:

xattr -cr ./IDAOS_V2_Mac_AppleSilicon
chmod +x ./IDAOS_V2_Mac_AppleSilicon
./IDAOS_V2_Mac_AppleSilicon

*(Note: If your Mac file is named idaos_v2_darwin_arm64 inside your zip folder, replace IDAOS_V2_Mac_AppleSilicon with the exact filename in your folder. The xattr -cr command strips Apple's download quarantine flag, and chmod +x grants execution permission.)*
